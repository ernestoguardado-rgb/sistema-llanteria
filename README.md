# Sistema Llantería - Código fijo

## Instalación
1. Instala Node.js LTS.
2. Abre terminal dentro de esta carpeta.
3. Ejecuta:

```bash
npm install
npm start
```

4. Abre:

```text
http://localhost:3000
```

Usuario inicial:
- Usuario: admin
- Clave: 1234

## Red local
Desde otra tablet/celular conectado al mismo WiFi:

```text
http://IP-DE-TU-PC:3000
```

## Base de datos
Se crea automáticamente en:

```text
backend/db/llanteria.db
```
